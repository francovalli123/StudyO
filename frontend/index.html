Preguntas Frecuentes

Todo lo que necesitás saber para empezar a optimizar tu estudio.

¿StudyO es gratuito? +

Sí, StudyO es completamente gratis. En el futuro se implementarán funcionalidades Premium de IA.

¿Cómo funciona el sistema de rachas? +

El usuario puede crear hábitos de estudio, los cuales podrá ir completando con la frecuencia que el usuario haya configurado. Cada vez que se complete un hábito, la racha aumentará. Está diseñado para crear el hábito de la constancia, no para quemarte estudiando 10 horas seguidas.

¿Sirve para cualquier carrera universitaria? +

Absolutamente. StudyO es agnóstico a la materia. Ya sea que estudies Ingeniería, Medicina, Derecho o Artes, la estructura de organización y los principios de estudio activo funcionan para cualquier disciplina.

¿Puedo usarlo en mi celular? +

Sí. StudyO es una aplicación web totalmente responsiva. Podés acceder desde tu navegador en el celular, tablet o computadora y tu progreso se sincroniza automáticamente en tiempo real.
